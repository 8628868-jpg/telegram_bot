# Telegram Bot для получения chat_id

Бот сохраняет chat_id всех, кто пишет `/start`, и позволяет отправлять сообщения всем сохранённым пользователям.

## Установка

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота
3. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/8628868-jpg/telegram_bot.git
   cd telegram_bot
